Not connected
Two automatic scenarios:

1. queue — ask "Will it rain today?". The LLM speaks a preamble, the client fires the queue inject, and it appends seamlessly behind the preamble while the function loads.

2. default — stay silent for 2s after the agent finishes. The client fires the default inject ("Are you still on the line?") — but if you start talking just as the timer fires, the server returns InjectionRefused.
